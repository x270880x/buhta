# tiles/ — локальные тайлы карты

Подложка скачана по площади с. Бухта (полигоны участков + буфер ~150 м), чтобы карта не
зависела от чужих серверов: официальные серверы OpenStreetMap заблокировали приложение
(403 «App is not following the tile usage policy»), и вся карта превращалась в стену
плиток «Access blocked».

| папка | источник | зумы | файлов |
|---|---|---|---|
| `sat/{z}/{x}/{y}.jpg` | Esri World Imagery | 13–18 | 1 302 |
| `osm/{z}/{x}/{y}.png` | OSM France (osmfr) | 13–19 | 4 512 |

**Почему спутник только до z18:** выше Esri по этой территории отдаёт серую плитку
«Map data not yet available». Google даёт z19–20, но это растянутый z18, новых деталей нет.
В карте выставлен `maxNativeZoom: 18` — Leaflet растягивает z18 сам, пустых квадратов не будет.

Внешние источники остаются запасными: если тайла нет локально, слой подставит удалённый URL
(см. `localTiles()` в index.html).

Обновить: `scratchpad/fetch_tiles.py` (качает через curl — urllib в Python 3.14 не проверяет
сертификаты). Скрипт пропускает уже скачанные файлы, так что можно запускать повторно.
